# 뉴스함 — 한국어 원문 읽기

`#/news`에서 한국어 기사 목록을 보고, 카드를 누르면 `#/news/read?topic=분야&article=기사주소`에서 원문 본문과 기사 사진을 읽습니다. NewsData.io 연결과 요약·발췌 대체 표시는 제거했습니다. 기존 NewsData 키는 사용할 수 없습니다.

## 선정: World News API

2026-09-27 확인한 공식 명세 기준:

- [Search News](https://worldnewsapi.com/docs/search-news/)는 기사 전문인 `text`, 제목, 날짜, 작성자, 대표 이미지, 언어, 국가, 카테고리를 반환합니다. `summary`는 사용하지 않습니다.
- [Extract News](https://worldnewsapi.com/docs/extract-news/)는 기사 URL에서 전문 `text`와 `images[]`를 반환합니다. 이미지에는 URL, 설명(`title`), 선택적 크기가 들어갑니다. 상세 진입 시 이 API를 호출하여 대표 이미지 한 장에 그치지 않고 반환된 사진 전체를 표시합니다.
- [한국 뉴스 지원](https://worldnewsapi.com/docs/news-sources/south-korea-news-api/): 한국어 `ko`, 한국 매체 `kr`를 지원합니다. 번역이나 AI 요약을 만들지 않습니다.
- [무료 플랜](https://worldnewsapi.com/pricing/): 하루 50포인트, 초당 1요청, 동시 1요청, 최근 1개월 검색, 제공사 링크 필수입니다. 무료 한도 소진 후 추가 호출은 차단됩니다.
- 검색은 1포인트 + 결과당 0.01포인트(12건이면 1.12포인트), 원문·이미지 추출은 `analyze=false`로 2포인트입니다. 실제 사용량은 API 응답의 quota 헤더와 계정 콘솔이 기준입니다.

### 제공 범위와 한계

**한국어 원문과 여러 이미지를 지원하는 무료 API를 연결한 것이며, 모든 언론사의 원문·이미지가 100% 완전하게 추출됨을 보장하는 것은 아닙니다.** 원문 사이트의 접근 제한·로그인·유료벽, 수집 실패, 기사 변경에 따라 누락되거나 이미지가 깨질 수 있습니다. 이를 우회하는 코드는 없습니다.

API는 본문 텍스트와 이미지 목록을 별도로 주며 원문 HTML의 이미지 삽입 위치를 주지 않습니다. 앱은 대표 이미지를 상단에, 본문 전체를 가운데에, 나머지 사진과 설명을 하단에 표시합니다. 원래 웹페이지의 광고·내비게이션·레이아웃을 복제하지 않습니다. API가 추출한 텍스트는 번역·요약·길이 자르기 없이 표시하고 줄바꿈을 유지합니다.

검색 응답은 한국 매체의 한국어 기사 중 본문이 있는 결과만 표시합니다. 추출 응답도 한국어와 본문 존재를 검증합니다. 본문이 없으면 요약으로 대체하지 않고 오류와 원문 링크를 제공합니다. 추가 추출만 실패하면 이미 받은 검색 응답의 본문을 유지하고 사진 조회 실패를 안내합니다.

API 카테고리 필터는 비영어 기사에서 분류 누락이 있을 수 있다고 공식 문서가 안내합니다. 기본값은 **전체**이며 특정 분야가 비어 있으면 전체에서 확인할 수 있습니다.

### 비교한 대안

- NewsData.io 무료: 전문 미제공이라 제외했습니다. [공식 플랜 안내](https://newsdata.io/blog/pricing-plan-in-newsdata-io/)
- 네이버 뉴스 검색: 설명과 링크 중심으로 전문·이미지 전체를 제공하지 않습니다. [공식 명세](https://developers.naver.com/docs/serviceapi/search/news/news.md)
- 한국어 위키뉴스: 원문 공개 API 후보였으나 국내 최신 종합뉴스 용도로 기사 수·갱신 범위가 좁아 선택하지 않았습니다. [대문](https://ko.wikinews.org/wiki/위키뉴스:대문)

## 연결

1. [World News API 콘솔](https://worldnewsapi.com/console/)에서 무료 계정과 키를 발급합니다.
2. 뉴스함의 **뉴스 API 키**에 입력하고 **뉴스 연결하기**를 누릅니다.
3. 키를 지우거나 바꾸려면 목록 하단의 **뉴스 연결 해제**를 누릅니다. 저장된 키가 삭제되고 입력 화면으로 돌아갑니다.

키는 사용자가 뉴스함에 한 번 입력하면 이 사이트의 localStorage(`rokcha.world-news-api-key`)에 저장하고 `x-api-key` 요청 헤더로 전달합니다. 같은 브라우저에서 새로고침하거나 창을 다시 열어도 자동 연결됩니다. 다른 브라우저·기기에는 동기화되지 않으며 사이트 데이터를 지우면 다시 입력해야 합니다. 상세 URL도 목록 조회 없이 자동 연결하여 해당 기사 추출 API를 호출합니다. 키는 코드·문서·URL·DB에 넣지 않습니다. 저장이 차단되면 입력 화면에 오류를 표시하며 저장에 성공한 것처럼 안내하지 않습니다. 공용 기기에서는 사용 후 연결을 해제합니다.

기사 API 요청은 `https://api.worldnewsapi.com`에만 보냅니다. 작업실 세션·Supabase 인증·쿠키를 포함하지 않습니다. 이미지 요청에는 API 키를 붙이지 않으며 HTTPS 주소만 허용합니다. 브라우저 직접 호출 방식이므로 사용자는 자신의 개발자 도구에서 본인 키를 확인할 수 있습니다. 서버·SQL·환경 변수 변경은 필요 없습니다.

## 구성과 요청

- `features/news/api.ts`: 응답 검증·URL 검증·한국어/국가 필터·이미지 중복 제거·단일 요청 큐·동시 동일 요청 병합.
- `features/news/use-news.ts`: 화면에 필요한 목록 상태와 재시도, 분야 변경 시 늦은 응답 차단.
- `pages/news-page.tsx`: 키 연결·카테고리·현재 목록의 제목/본문/작성자 검색.
- `pages/news-article-page.tsx`: 원문 추출·전체 텍스트·사진/설명·원문 링크·재시도.

`search-news`에는 `language=ko`, `source-countries=kr`, `sort=publish-time`, `sort-direction=DESC`, `number=12`를 보냅니다. 전체 이외에는 `categories`도 보냅니다. 자동 더보기나 배경 갱신은 없습니다. 분야 이동과 목록 새로고침은 검색 요청, 기사 진입은 추출 요청입니다. 목록 복귀 시 검색어·카드 포커스를 복원하고 목록을 다시 조회합니다.

동시 요청은 하나로 직렬화하고 시작 간격은 1.1초 이상입니다. 20초 제한, 429의 Retry-After, 402의 무료 한도 소진, 401/403의 키/권한 오류를 처리합니다. 자동 재시도로 포인트를 소진하지 않습니다. 키 변경 시 대기 요청과 늦게 도착한 응답을 폐기합니다. 오류는 화면 안에 표시하며 뉴스 토스트를 만들지 않습니다.

[제공사 이용 조건](https://worldnewsapi.com/terms/)에 맞춰 이전의 분야별 10분 캐시를 제거했습니다. 응답은 화면 표시 중 React 상태로만 유지하고 응답 캐시·DB 저장·다운로드·재판매 기능은 만들지 않습니다. fetch에는 `cache=no-store`를 지정합니다. 텍스트와 사진의 권리는 원 출처에 있으며 API 접근 권한이 무제한 재배포 허가를 뜻하지 않습니다. 목록·상세 하단에는 무료 플랜의 필수 제공사 링크를 표시합니다.

외부 데이터는 React 텍스트로 렌더링하며 HTML을 실행하지 않습니다. 이미지 실패 시 사진 자리에 안내를 남기고 설명을 보존합니다. 모든 사진을 수신 순서로 표시하되 같은 URL만 중복 제거합니다.

공식 문서와 인증 없는 API 오류 응답의 CORS 지원은 확인했습니다. **실제 무료 키를 이용한 한국어 기사 전문·이미지 수신과 실제 매체별 추출 완전성은 아직 검증하지 않았습니다.** 개인 키를 연결한 뒤 실제 기사에서 확인해야 하며 모의 테스트 통과를 실제 기사 검증으로 간주하지 않습니다.
