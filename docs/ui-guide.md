# UI 재사용 가이드

영단어 공부방의 제목·검색창·가리기 모드는 하나의 고정 PageHeader에 배치합니다. 단어 개수는 표시하지 않고, 가리기 모드는 도구 행의 오른쪽 끝에 정렬합니다. 모바일에서 줄이 바뀌어도 오른쪽 정렬과 상단 고정을 유지합니다.

수정 버튼은 공통 `Button`의 `ghost`, 삭제 버튼은 `destructive-ghost`를 사용합니다. 삭제는 기본 배경 없이 붉은 글자·아이콘을 표시하고 hover 시에만 옅은 붉은 배경을 표시합니다. 아이콘 전용 삭제, 전체 삭제, 삭제 확인 버튼에도 같은 변형을 적용합니다. 영단어 상세의 수정·삭제 버튼은 하단 오른쪽 끝에 배치합니다.

영단어 목록은 최소 너비 8rem을 기준으로 열 수가 늘어나는 단어 전용 버튼 그리드입니다. 카드에는 단어만 표시하고, 선택 상태는 녹차색과 aria-pressed로 구분합니다. 선택하면 오른쪽 ‘선택한 단어’ 영역에 품사별 모든 뜻과 수정·삭제 버튼을 표시하며 수정은 기존 Dialog를 사용합니다. 1024px 미만에서는 상세 영역을 목록 아래에 배치하고 선택 시 상세 제목으로 포커스를 옮깁니다. 긴 단어와 뜻은 줄바꿈하며, 검색 결과에서 선택 단어가 제외되거나 삭제되면 선택 안내를 표시합니다.

영단어 공부방 제목은 📖 장식 이모지를 사용하고 aria-hidden으로 접근성 이름에서 제외합니다. 단어 검색은 대소문자 구분 없이 영단어만 대상으로 합니다. 검색 입력은 포커스 링을 안쪽에 그리고 주변 여백을 확보해 잘림을 방지합니다. 단어 테스트와 상시 새로고침 버튼 대신 ‘단어 가리기 모드’ Switch를 표시합니다. 모드를 켜면 선택을 바꿔도 품사·뜻을 표시하지 않으며, 끄면 현재 단어의 뜻을 표시합니다. 단어·뜻 수정은 Dialog에서 수행합니다. 편집 후 실행 버튼, 삭제 후 추가 버튼으로 포커스를 돌려줍니다. 토스트 ID는 vocabulary-mutation입니다.

## 기본 디자인

- 모든 화면과 토스트의 기본 글꼴은 고운돋움(`Gowun Dodum`)입니다. 400 굵기의 폰트를 `main.tsx`에서 한 번 로드합니다.
- Tailwind v4의 CSS 기반 설정을 사용합니다. `tailwind.config.js`나 PostCSS 설정 파일은 필요하지 않습니다.
- 색·간격은 Tailwind 클래스를, 테마 색은 `globals.css`의 CSS 변수를 사용합니다.
- `bg-background`, `bg-card`, `text-foreground`, `text-muted-foreground`, `border-border`, `bg-primary`를 우선합니다.
- 현재 라이트 테마만 구현했습니다. 다크 테마 도입 시 CSS 토큰과 Sonner의 `theme`을 함께 연결하세요.

## 버튼과 스타일 조합

```tsx
import { Button } from '@/components/ui/button'
import { cn } from '@/lib/utils'

<Button>저장</Button>
<Button variant="outline" size="sm">취소</Button>
<Button asChild><a href="/">작업실로</a></Button>
<div className={cn('rounded-lg border', className)} />
```

버튼의 종류는 `default`, `secondary`, `outline`, `ghost`, `destructive`, `link`입니다. 크기는 `default`, `sm`, `lg`, `icon`입니다. 폼 안에서 제출하지 않는 버튼은 `type="button"`을 명시합니다.

## Sonner

```tsx
import { toast } from 'sonner'

toast.success('저장했어요.')
toast.error('저장하지 못했어요.', { description: '잠시 후 다시 시도해 주세요.' })
toast.info('새로운 알림이 있어요.')

// 실제 비동기 저장 함수가 있을 때:
toast.promise(saveChanges(), {
  loading: '저장 중이에요…',
  success: '저장했어요.',
  error: '저장하지 못했어요.',
})
```

`Toaster`는 `app/providers.tsx`에 이미 설치되어 있습니다. 페이지마다 추가하지 마세요. 실제 성공·실패 결과가 확정되는 이벤트에서 알림을 호출하고, 렌더 중 호출하지 않습니다.

## shadcn/ui 컴포넌트 추가

기존 버튼·Sonner는 프로젝트 디자인에 맞게 조정한 로컬 소스입니다. 필요한 UI만 CLI로 추가하세요.

```sh
npx shadcn@latest add dialog input label
```

현재 PC의 로컬 Node를 쓴다면:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/npm.ps1 exec -- shadcn@latest add dialog input label
```

`components.json`에 경로와 스타일이 지정되어 있습니다. CLI 실행 후 기존 토큰·글꼴·컴포넌트 변경 내용을 검토하고 `npm run check`를 실행하세요. 기존 파일을 덮어쓰는 `--overwrite`는 수정 사항을 확인한 뒤에만 사용합니다.

- 320px 모바일부터 데스크톱까지 가로 넘침이 없는지 확인합니다.
- Tab으로 본문 바로가기·브랜드 링크·버튼을 이동할 수 있어야 합니다.
- 여덟 메뉴의 화면 전환·선택 표시와 브라우저 뒤로 가기를 확인합니다. 캘린더의 이전 달·다음 달·오늘 버튼을 확인합니다.

- 글꼴 요청이 앱 자산에서 로드되는지 확인합니다.

## 메모함

작업실 메모는 메모함과 별개인 한 장짜리 메모장입니다. 데스크톱에서는 오늘 일정과 다가오는 일정을 왼쪽에 쌓고, 오른쪽 메모장은 일정의 절반 너비로 두 카드 높이를 채웁니다. 모바일에서는 세 영역이 한 열로 배치됩니다. 모든 페이지의 오른쪽 아래 버튼으로 같은 메모를 편집하며 이모지는 현재 선택 영역에 삽입합니다. 비모달 Radix Dialog로 Escape 닫기와 트리거 포커스 복귀를 지원합니다. 위쪽 이동 손잡이를 마우스·터치로 드래그하거나 방향키로 이동하며, 화면 크기가 바뀌어도 창을 화면 안에 유지합니다. 내용은 Supabase에 자동 저장됩니다. 입력이 멈춘 뒤 500ms 후 저장하며, 진행 중인 저장이 끝나면 다음 변경을 순서대로 저장합니다. 저장 실패는 토스트 대신 편집기 하단에 안내합니다.

폴더별 보기를 기본으로 하며 폴더를 펼쳐 메모와 하위 폴더를 확인합니다. 폴더 추가 시 접고 펼칠 수 있는 트리에서 최상위 또는 기존 폴더를 선택합니다. 메모 저장·이동에는 전체 폴더 경로를 표시하며, 폴더 내부 메모는 작성일 최신순입니다. 메모 추가와 카드 클릭은 별도 상세 페이지로 이동합니다. 제목·넓은 본문 편집 영역과 폴더 선택을 제공하며 모바일에서는 한 열로 배치합니다. 상단 저장 버튼으로 저장하면 선택한 폴더로 돌아가며 실패 시 입력을 유지합니다. 폴더 편집·메모 이동에는 로컬 shadcn `Dialog`, 삭제에는 `AlertDialog`를 사용합니다. 폴더 삭제는 모든 하위 폴더와 포함된 메모 수, 복구 불가 안내를 표시합니다.

편집 및 삭제 대화상자는 배경 클릭으로 닫을 수 있습니다. 대화상자는 키보드 포커스를 내부에 유지하고 닫을 때 실행 버튼으로 돌려줍니다. 삭제로 버튼이 사라진 경우 폴더 추가 버튼으로 돌려줍니다. 저장 중에는 재제출과 닫기를 막고, 실패 시 입력과 대화상자를 유지합니다. 성공 알림은 기존 Toaster에 고정 ID로 전달합니다. `npm run test:ui`에서 이 흐름과 320px 모바일 배치를 검사합니다.



## 링크함

메모함과 동일하게 최상위 폴더 → 하위 폴더를 탐색합니다. 링크 카드는 모바일 1열, 넓은 화면 2~3열이며 이미지는 16:9로 표시합니다. 카드 클릭은 새 탭 이동, 아래 아이콘은 수정·폴더 이동·삭제입니다. 이미지 조회 실패나 이미지 로드 오류는 녹차색 기본 카드로 대체합니다. 편집 창에서 미리보기 가져오기 또는 이미지 주소 직접 입력을 선택할 수 있습니다. 성공 토스트는 `links-mutation` ID로 중복을 방지합니다.



## 일정과 날짜별 노트

시간 입력은 `1` → `01:00`, `130` → `01:30`, `오후 1시` → `13:00`처럼 짧게 입력해도 자동 정리합니다. 입력 중에는 원문을 유지하고 입력란을 벗어나면 표준 시간을 표시하며, Enter로 바로 저장해도 같은 결과를 사용합니다. 빈 시간은 종일로 저장하고 잘못된 시간은 저장을 막습니다. 공통 TimePicker를 사용하는 수업 시간에도 단축 입력을 지원하되 수업 시간은 필수입니다.

월간 캘린더 상단의 ‘일정 추가’ 버튼에서도 기존 일정 편집기를 열 수 있습니다. 오늘이 속한 달에서는 오늘, 다른 달에서는 해당 달 1일을 기본값으로 사용하며 날짜를 직접 입력하거나 달력에서 선택해 일정을 저장합니다.

캘린더 날짜 칸 전체가 날짜 상세 페이지로 연결됩니다. 상세 페이지에서 일정은 여러 개, 노트는 하루에 하나를 작성합니다. 이미 노트가 있는 날짜에서는 추가 대신 기존 노트를 수정·삭제합니다. 날짜 변경으로 노트가 중복되는 경우에도 저장을 막습니다. 일정 추가·수정 창은 일정 전용이며 유형 선택은 없습니다. 노트는 별도 추가·수정 창에서 제목 없이 내용만 작성하고 공백만 저장할 수 없습니다. 기존 노트 제목은 본문 앞에 보존하며, 날짜 상세와 작업실 오늘 목록에도 노트 본문만 표시합니다. 이전에 중복 작성한 노트는 제목과 본문을 보존해 한 장으로 합쳐 표시합니다. 일정은 선택적으로 시간을 지정하며 시간 미지정은 종일, 노트는 날짜별 확인 내용을 담습니다. 항목 클릭으로 수정·삭제하고 삭제 전 확인을 거칩니다. 작업실 오늘 목록은 두 유형을 함께, 다가오는 목록은 내일 이후의 일정만 날짜·시간순으로 D-day와 함께 표시합니다. 날짜 차이는 일광절약시간과 무관하게 달력 날짜 기준으로 계산합니다. 저장은 Supabase에서 처리하며 실패 시 편집 내용을 보존합니다.

토스트는 아주 옅은 녹차색 배경·얇은 테두리·은은한 그림자를 사용합니다. 성공·안내 아이콘은 녹차색, 주의는 차분한 황토색이며 오류만 옅은 붉은 배경과 붉은 아이콘으로 구분합니다. 본문은 진한 기본 글자색, 설명은 보조 글자색을 유지합니다. 토스트의 닫기 X 버튼은 표시하지 않습니다. 색상은 기존 테마 토큰을 사용합니다. 캘린더 알림은 고정 ID로 중복을 방지합니다.

날짜 상세 주소는 #/calendar/YYYY-MM-DD이며 새로고침·뒤로 가기를 지원합니다. 월간 캘린더로 돌아가면 해당 날짜의 달을 표시합니다. 오늘 목록은 시간 지정 일정의 오름차순, 종일 일정, 노트 순서입니다. 작업실 일정 카드는 높이를 고정하고 목록만 내부 스크롤되며 키보드로도 스크롤할 수 있습니다.

## 카드 배치와 폴더 이동

메모함·링크함의 폴더 카드는 640px 미만 1열, 640px 이상 2열, 1280px 이상 4열로 배치합니다. 콘텐츠 카드는 기존 1·2·3열 배치를 유지합니다. 메모 작성 날짜는 카드에 표시하지 않습니다. 메모·링크 작성과 이동에서 공통 계층형 FolderPicker를 사용하며 콘텐츠는 최상위를 선택할 수 없습니다. 폴더 이동 버튼에서는 최상위 또는 다른 폴더를 선택하며 자기 자신과 하위 폴더는 선택지에서 제외합니다.

월간 달력에는 일정만 표시하고 노트는 날짜 상세와 오늘 일정에서 확인합니다. 오늘 상세 보기·캘린더 보기 버튼은 작업실 각 섹션의 제목과 같은 줄 오른쪽에 둡니다.

## 간결한 화면 구성

캘린더 공휴일은 날짜 숫자와 한국어 이름에 `text-destructive`를 사용합니다. 오늘이 공휴일이면 옅은 붉은 원형 배경과 빨간 숫자를 함께 표시합니다. 이름은 날짜 옆에 두고 좁은 모바일에서는 다음 줄로 배치하며 최대 두 줄로 표시합니다. 긴 이름 전체는 날짜 링크의 title과 접근성 설명으로 제공합니다. 공휴일 조회 실패·미제공 연도만 하단에 안내하며 성공 토스트는 표시하지 않습니다.

날씨는 지역 선택을 고정 헤더에 두고 현재 기온·체감온도·습도·바람, 오늘 예상 강수량·최대 강수 확률, PM10·PM2.5 예측 농도를 카드로 표시합니다. 시간대별 12시간 예보는 키보드로 가로 스크롤하며 5일 예보는 아래에 배치합니다. 누락 값은 0 대신 ‘—’로 표시하고, 조회 실패 시 재시도와 이전 데이터 여부를 안내합니다. 미세먼지는 국내 농도 구간에 따른 참고 등급(좋음·보통·나쁨·매우 나쁨)을 크게 표시하고 수치는 작게 표시합니다. 기준 시각과 카드별 부연 설명은 생략합니다. 모델 예측값이라는 설명과 등급 기준 출처는 하단에 둡니다. 현재 위치 버튼으로 브라우저 위치 권한을 요청하며, 실패 시 기존 지역을 유지하고 오류를 안내합니다. 캘린더는 같은 위치의 오늘부터 최대 16일 예보를 날짜 오른쪽 이모지로 표시하고, 예보 없는 날은 비워 둡니다.

입장 화면은 나뭇잎 아이콘을 붙인 ‘록차의 작업실’ 제목, 보안코드 입력란, ‘들어가기’ 버튼을 중앙에 배치합니다. 중복 브랜드·자물쇠 아이콘·소개 문구는 생략하고 접속 확인 중 상태와 실제 오류 안내는 필요한 때만 표시합니다.

시간 입력 예시와 일정의 종일 안내는 입력란 아래에 표시하지 않습니다. 데스크톱의 작업실 나가기 버튼은 왼쪽 사이드바 맨 아래에 두고 화면 하단에서 16px 여백을 유지합니다.

페이지 제목 위 소개 문구와 사이드바의 나의 공간·하단 슬로건은 표시하지 않습니다. 다가오는 일정은 D-day와 제목을 표시하며 오늘 아직 기준 시각이 지나지 않은 일정도 포함합니다. 일정이 24시간 미만 남으면 제목과 같은 행의 오른쪽 끝에 시계 아이콘과 남은 시간·분을 표시합니다. 1분 미만은 “1분 미만 남음”으로 안내하고, 30초마다 및 화면 복귀 시 갱신하며 기준 시각이 지난 일정은 목록에서 제외합니다. 종일 일정은 해당 날짜 23:59를 기준으로 남은 시간을 계산합니다. 오늘 일정 카드는 왼쪽 일정 목록과 오른쪽 노트 본문을 같은 너비의 2열로 항상 함께 표시합니다. 모바일에서도 좌우 배치를 유지하고 각 영역은 독립적으로 스크롤합니다. 상단의 오늘 일정·다가오는 일정 탭으로 카드 내용을 전환합니다. 메모함 폴더 카드는 📁 이모지와 옅은 녹차색 배경, 메모 카드는 📝 이모지와 흰 배경·작은 그림자로 구분합니다. 장식 이모지는 접근성 이름에서 제외합니다.

날짜 상세는 넓은 화면에서 일정과 노트를 같은 너비의 2열로 배치하고, 좁은 화면에서는 1열로 전환합니다. 두 카드의 상단과 높이를 맞추고 여백·테두리·그림자를 통일합니다. 작업실 메모 헤더는 다른 섹션처럼 별도 배경색 없이 아이콘과 제목만 표시합니다.

## 수업 시간표

나의 작업실·캘린더·수업 시간표·메모함·링크함 제목에는 각각 🍵·📅·📚·📝·🔗 장식 이모지를 왼쪽에 배치하고 `aria-hidden`으로 접근성 이름에서 제외합니다. 다섯 화면의 제목 아래 소개 문구는 표시하지 않습니다.

시간표는 등록된 수업 중 가장 이른 시작 시각이 속한 시간부터 표시합니다. 예를 들어 첫 수업이 오후 2시라면 14시가 맨 위이며, 수업이 없으면 오전 8시부터 표시합니다. 종료 범위는 최소 오후 10시이며 더 늦게 끝나는 수업이 있으면 확장합니다. 수업 블록은 왼쪽 강조선과 둥근 모서리 없이 제목만 가로·세로 중앙에 표시하며, 시간과 메모는 편집 창과 툴팁에서 확인합니다.

월–일 7열과 시간 축으로 매주 반복되는 수업을 표시합니다. 수업 색상은 globals.css의 11가지 전용 토큰을 사용하고 새 수업마다 기본 색상을 순환합니다. 여러 요일 선택, 시작·종료 시간, 이름과 메모를 편집할 수 있습니다. 종료가 시작보다 빠르거나 같으면 저장하지 않으며 같은 요일의 겹치는 시간도 안내합니다. 주간 표는 시간 범위에 맞는 전체 높이로 펼치고 페이지를 세로로 스크롤합니다. 좁은 화면의 가로 스크롤은 유지하며 고정된 요일 줄과 본문의 가로 위치를 서로 맞춥니다. 편집은 Dialog, 삭제 확인은 AlertDialog이며 삭제 시 반복 요일 전체에 적용합니다. 성공 토스트는 timetable-mutation ID로 중복을 방지합니다.

메모함과 링크함의 제목 아래 소개 문구는 표시하지 않습니다. 링크함의 폴더 카드와 빈 폴더 안내에는 메모함과 같은 📁 장식 이모지를 사용합니다.

공통 본문은 최대 너비 제한 없이 사이드바와 화면 좌우 여백을 제외한 공간을 채웁니다. 플로팅 메모장은 최대 너비 40rem, 본문 높이 42rem으로 넓히되 작은 화면에서는 화면 너비에서 24px, 높이에서 8rem을 뺀 크기 안에 맞춥니다. 이동 후에도 화면 안에 유지합니다.

작업실 메모의 이모지 도구는 18가지를 제공하며, 저장 완료 상태는 ‘저장됨’으로 표시합니다. 플로팅 메모장은 바깥 클릭으로도 닫히며 자동 저장과 초안 상태는 유지됩니다. 사용자 화면에는 Supabase 이름을 표시하지 않고, 캘린더·시간표의 정적인 저장 안내 문구는 생략합니다. 링크 카드에는 추가 날짜와 설명이 없을 때의 기본 안내 문구를 표시하지 않습니다.

작업실 메모는 placeholder 없이 표시하고 헤더의 ‘이모지’ 버튼으로 18가지 이모지 도구를 접고 펼칩니다. 기본은 접힌 상태이며 입력 위치에 이모지를 삽입합니다. 수업과 일정 시간은 공통 TimePicker에서 HH:mm 형식으로 직접 입력하거나 시계 버튼의 shadcn Popover·Select로 시·분을 선택합니다. 모든 분(00~59)을 지원하며 잘못된 시간은 저장하지 않습니다. 일정은 빈 시간 또는 종일로 설정 버튼으로 종일 일정을 저장합니다. 좁은 화면에서는 시작·종료 입력을 세로로 배치합니다. 일정·노트 날짜는 shadcn Popover와 Calendar의 한국어 달력으로 선택하거나 YYYY-MM-DD로 직접 입력합니다. 선택 후 팝업을 닫고 달력 버튼으로 포커스를 돌려줍니다.

각 화면의 제목·상단 버튼은 공통 PageHeader로 묶어 페이지 스크롤 시 위에 고정합니다. 메모함·링크함은 폴더 경로와 개수·새로고침도 헤더에 포함합니다. 헤더는 불투명한 배경과 z-30을 사용하고 대화상자·팝오버와 플로팅 메모는 그 위에 표시합니다.

월간 캘린더는 월~일 순서이며 제목·월 이동 버튼·요일 줄을 함께 고정합니다. 수업 시간표도 제목·추가 버튼·요일 줄을 함께 고정합니다. 헤더 높이에 맞춘 스크롤 여백으로 키보드 이동 시 내용이 헤더 뒤로 가려지는 것을 줄입니다.

뉴스함은 📰 제목과 카테고리·검색·새로고침을 고정 헤더에 둡니다. World News API의 공식 분야를 한국어 버튼으로 표시하고 기본값은 전체입니다. 카드 링크로 별도 상세 페이지를 열며 최대 48rem 폭에 본문 전체와 대표 이미지, 나머지 사진·설명을 순서대로 배치합니다. 요약·발췌 대체 표시는 없으며 본문을 받지 못하면 오류를 표시합니다. 이미지 실패 안내와 설명은 남깁니다. 직접 진입과 새로고침 후 자동 연결을 지원하고, 목록 복귀 시 검색어와 카드 포커스를 복원합니다. 연결 화면에 이 브라우저의 키 저장과 공용 기기 연결 해제를 안내하며, 목록 하단의 뉴스 연결 해제로 저장된 키를 지웁니다. 무료 한도는 연결 화면에 안내하며 목록·상세 하단에 World News API 링크를 표시합니다. 뉴스 토스트는 발생시키지 않습니다.



날씨 카드의 아이콘과 제목은 한 줄로 나란히 배치하고 PM10·PM2.5 배지는 생략합니다. 현재 날씨 제목에는 지역명만 표시합니다. 시간대별 날씨의 부연 설명과 캘린더 하단 범례·지역 링크·예보 범위·출처 줄은 표시하지 않습니다. 날씨 출처는 날씨 페이지 하단에서 확인합니다. 캘린더 날씨 조회 오류 안내는 실패 시에만 표시합니다.



작업실 일정 전환은 두 개의 분할 탭으로 표시하며 방향키로 이동합니다. 전환 시 카드 높이는 유지하고 내용에 짧은 페이드 효과를 적용하며 동작 줄이기 설정을 존중합니다. 아래 할 일 리스트는 입력란, 완료 체크, 인라인 수정과 삭제 확인을 제공합니다. 우선순위가 높은 항목부터 표시하고 새 항목은 맨 아래에 추가합니다. 완료 항목은 취소선으로 표시하되 순위를 유지합니다. 전체·할 일·완료한 일 필터는 녹차색 분할 버튼과 개수로 표시합니다. 오류 시 입력을 유지하고 편집 종료 시 수정 버튼, 삭제 후 입력란으로 포커스를 복원합니다. 알림은 todo-mutation 고정 ID를 사용합니다.

별도 손잡이 없이 각 할 일 영역을 마우스·터치로 드래그하면 녹차색 삽입선이 나타납니다. 목록 가장자리에서는 자동 스크롤합니다. 할 일 내용에 포커스를 두고 ↑↓로 한 칸, Home/End로 보이는 목록의 처음/끝으로 이동하며 Escape로 드래그를 취소합니다. 필터 상태에서는 보이는 항목끼리만 순서를 바꾸고 숨겨진 항목의 위치는 유지합니다. 순서 저장 후 할 일 내용에 포커스를 복원하고 변경 결과를 스크린 리더에 알립니다. 저장 실패 시 기존 순서를 유지하고 실패 알림의 다시 불러오기로 최신 목록을 가져올 수 있습니다. 완료 필터에서 새 항목을 추가하면 할 일 필터로 전환해 추가한 항목을 확인할 수 있습니다.

작업 성공 토스트에는 대상과 실제 동작(추가·수정·삭제·이동·완료·완료 취소)을 명시합니다. 할 일 헤더는 완료/전체 개수와 새로고침 대신 전체 삭제 버튼을 표시합니다. 필터별 개수는 필터 버튼에 유지합니다. 오늘 일정·다가오는 일정 탭에는 각각 CalendarDays·CalendarClock 장식 아이콘을 배치합니다.

할 일 입력란은 높이 44px과 좌우 16px 여백을 사용하며, 체크박스는 포인터 커서를 표시합니다. 순서 변경 안내 문구는 화면에 표시하지 않습니다. 체크박스·수정·삭제 버튼에서는 드래그를 시작하지 않습니다. 플로팅 메모장은 별도 이동 바 없이 기존 제목·연필 아이콘·빈 헤더 영역을 잡아 이동합니다. 이모지와 닫기 버튼은 같은 헤더에 두고 이동 동작에서 제외합니다.

전체 삭제는 ‘전체 삭제하시겠습니까?’ AlertDialog에서 전체 개수와 복구 불가를 안내합니다. 기본 포커스는 취소이며 확인해야만 완료 항목·필터로 숨긴 항목을 포함해 모두 삭제합니다. 빈 목록·불러오기·저장·편집·드래그 중에는 버튼을 비활성화합니다. 실패 시 확인창과 기록을 유지하고 다시 불러오기 후 재확인합니다. 삭제 성공 후 입력란으로 포커스를 돌려줍니다.
